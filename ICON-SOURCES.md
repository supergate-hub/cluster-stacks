# Application Icon Sources

The catalog packages vendor upstream project icons so a released catalog is
self-contained and Launcher never fetches product artwork from arbitrary remote
URLs at request time.

| Application | Source | Pinned revision |
| --- | --- | --- |
| Argo CD | [CNCF artwork Argo icon](https://github.com/cncf/artwork/blob/93aebe4b8de8b763b7e3cdc2ad185b19fdc46989/projects/argo/icon/color/argo-icon-color.svg) | `93aebe4b8de8b763b7e3cdc2ad185b19fdc46989` |
| Headlamp | [Headlamp light icon](https://github.com/kubernetes-sigs/headlamp/blob/v0.43.0/frontend/src/resources/icon-light.svg) | `v0.43.0` |
| MLflow | [MLflow icon](https://github.com/mlflow/mlflow/blob/v3.14.0/assets/icon.svg) | `v3.14.0` |

The icons remain subject to their upstream project licenses and trademark
policies. They are copied without visual modification apart from whitespace
formatting.
